The one question to answer: standing where the back row will stand, can you tell which row is currently running — without being told, and without walking closer? Everything else is secondary.

Distance proxy shrinks the card so you can pre-screen at your desk. It is a rough stand-in for viewing distance, not a substitute — it cannot reproduce a projector's contrast loss, ambient light wash, or colour shift, which is exactly what is expected to kill the low-alpha candidate.

Verdicts you click are printed to the console as a one-line summary you can paste back.
